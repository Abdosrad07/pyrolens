# Matrice complète des écarts — PyroLens

**Niveaux de priorité** :
- **P0 — Bloquant** : empêche de démontrer que PyroLens répond au défi.
- **P1 — Critique** : affecte fortement la crédibilité scientifique ou le fonctionnement du MVP.
- **P2 — Important** : nécessaire pour un produit cohérent et convaincant.
- **P3 — Secondaire** : reportable après la soumission.
