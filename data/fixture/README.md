# Échantillon SYNTHÉTIQUE de démonstration

Ces fichiers sont **générés par `pyrolens fixture`** (graine déterministe) pour exécuter et tester le pipeline lorsque les données NASA réelles sont bloquées (Earthdata Login / FIRMS MAP_KEY absents de l'environnement).

**Ils ne contiennent aucune détection réelle.** Toute métrique calculée sur ces fichiers porte `data_origin = synthetic_fixture` et ne doit pas être interprétée comme un résultat scientifique sur le Cameroun.
